# 🏠 Dream Home

A modern and attractive **Dream Home** website created using **HTML and CSS**.
The website is designed for a home-building and renovation business.

## ✨ Features

* 🏠 Modern navigation bar
* 🌟 Attractive hero section
* 🛠️ Home building and renovation services
* 🖼️ Beautiful home images
* ✨ CSS animations
* 📞 Contact section
* 🎨 Clean and modern color theme
* 🔗 Easy navigation between sections

## 🛠️ Technologies Used

* HTML5
* CSS3

```text
│

└── images/
```
